## 5. Hard Firewall: Mini GIS Read-Only Isolation

Inspection of [`TemuanRepository::getMapPins()`](file:///e:/XAMPP/htdocs/SIDAK%20TEJO/app/Repositories/TemuanRepository.php#L462-L479) confirms strict read-only execution:

```php
public function getMapPins(?int $ulpIdFilter = null): array
{
    $builder = $this->model
        ->select('id, nomor_temuan, prioritas, status, latitude, longitude, alamat, detail_temuan')
        ->where('latitude IS NOT NULL')
        ->where('longitude IS NOT NULL')
        ->where("latitude != ''")
        ->where("longitude != ''")
        ->where("latitude != '0'")
        ->where("longitude != '0'")
        ->where('deleted_at IS NULL');

    if ($ulpIdFilter !== null) {
        $builder->where('ulp_id', $ulpIdFilter);
    }

    return $builder->findAll();
}
```

### Firewall Rules Enforced:
1. **Zero Topology Calls**: The mini map **never** calls `MultiFeederCompletionOrchestrator`, `TranslineCompletionService`, or `TranslineProposalService`.
2. **Zero Spatial Writes**: No geometry calculation, no line creation, no anchor point manipulation.
3. **Pure Presentation**: The map canvas (`#sidak-mini-map`) renders standard Leaflet circle markers (`L.circleMarker`) directly from the pre-filtered `$mapPins` array passed by `Dashboard::index`.
